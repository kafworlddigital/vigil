# Vigil for Macy

Separate apps: `com.kafworlddigital.vigil.m.ios` and `com.kafworlddigital.vigil.m.mac`.

Vigil is a focus tool. Choose one task; its face sleeps while you focus and wakes
when you drift. Settings offers Try everything, nudge styles, color glow, natural
US English speech, reminders, meeting warnings, breaks and an optional tired check.
Say Vigil or Virgil. On Mac, Control+Option+V also starts listening; Settings opens
from the menu bar, the face's right-click menu or Command+comma.

All generated answers and natural speech use the existing authenticated
Contabo vigil-brain. No provider keys, Tuck access or local generative model.
Server inference uses the free-model failover path. Apple speech recognition
stays on-device for wake words and commands; optional Apple Vision tired cues
also stay on-device. These do not call any external AI provider.

Speech is generated by Piper LJ Speech US English on the server and cached in the
edition's private device cache, bounded to 64 clips. Device playback follows the
current system output; there is no forced speaker route. If no server connection
or cached speech is available, the answer remains visible without local synthesis.

TestFlight uses Apple's verified app transaction to enrol each installation.
Per-device tokens and all saved focus data remain separate from Keith's edition.
No token or key is baked into a release. Friendly Allow cards precede microphone,
speech and camera requests. Optional tired checks default off; camera permission
is reused after the OS grants it. The camera never starts just from launch.
Voice only requires Microphone and Speech Recognition. Mac pointer reading has
its own explanatory Allow card for Accessibility and Screen Recording, shown
when What is this is requested. Declining screen access does not block voice.
The paired iPhone's current task stays available to next-step help on its face
screen, without first having to open the focus dashboard.

The M1/8 GB target retains the prepared idle improvements: no continuous idle face
or particle drawing, a shared pointer sampling clock, paused focus clocks when no
session runs, batched microphone telemetry and no local model/speech synthesis.
Wake listening is optional and off until enabled. A running microphone still uses
resources; near-zero idle must be measured on Macy's actual Mac, not inferred.

Delivery is one light Release archive for each Macy target after Keith's
checkpoint completion or 01:00 UK, using internal dd-macy and one compiler job.
Nothing is installed on Keith's devices. Upload, group assignment and Beta App
Review are independently read back; TestFlight status is distinct from device use.

US speech uses the Piper LJ Speech high model, trained from scratch on the public-domain LJ Speech dataset. Model card: https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_US/ljspeech/high/MODEL_CARD . The speech model runs only on the existing server and is not bundled in either app.

Speech waveforms can also use the existing private brain cache (64 clips across voices); request text is not written to logs or process arguments. The app Help distinguishes local recognition from server-generated speech.
